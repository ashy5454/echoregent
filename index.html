Drop-in integration

One-line change: point your OpenAI-compatible baseURL at EchoRegent.

🔌
One-line integration

Swap your OpenAI-compatible baseURL to EchoRegent's /v1 endpoint. No other code changes.

🔑
Bring your own provider key

Your OpenAI, Anthropic, or Gemini key travels in the x-llm-key header on each request — never stored server-side.

📊
Real usage headers on every response

x-cts-tokens-saved, x-cts-domain, x-cts-intent, x-cts-risk, and x-cts-compression-mode come back on every call.

bash
# provider = openai, anthropic, or gemini
curl https://your-echoregent-url/v1/chat/completions \
  -H "Authorization: Bearer YOUR_ECHOREGENT_KEY" \
  -H "Content-Type: application/json" \
  -H "x-llm-key: YOUR_OPENAI_KEY" \
  -H "x-llm-provider: openai" \
  -d '{"model":"gpt-4o","messages":[{"role":"user","content":"Hello"}]}'
javascript
import OpenAI from 'openai'

const client = new OpenAI({
  apiKey: 'YOUR_ECHOREGENT_KEY',
  baseURL: 'https://your-echoregent-url/v1',
  defaultHeaders: {
    'x-llm-key': 'YOUR_OPENAI_KEY',
    'x-llm-provider': 'openai',
  },
})

const res = await client.chat.completions.create({
  model: 'gpt-4o',
  messages: [{ role: 'user', content: 'Hello' }],
})
python
import requests

res = requests.post(
    "https://your-echoregent-url/v1/chat/completions",
    headers={
        "Authorization": "Bearer YOUR_ECHOREGENT_KEY",
        "x-llm-key": "YOUR_OPENAI_KEY",
        "x-llm-provider": "openai",
    },
    json={
        "model": "gpt-4o",
        "messages": [{"role": "user", "content": "Hello"}],
    },
)
print(res.json())
