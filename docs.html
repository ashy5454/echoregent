API documentation

Context plan

POST /api/context-plan classifies a request and returns its policy decision and context strategy without calling a model.

Context policy

GET and PUT /api/policy read and update the authenticated workspace policy. Protected domains and risks are always merged with CTS safety floors.

Cited memory

Use GET /api/memory/facts?query=… to retrieve current facts with source IDs. Correct or forget a fact with the matching fact endpoint.
