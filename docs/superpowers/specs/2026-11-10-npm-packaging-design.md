# EchoRegent npm distribution

The user supplied the release design: one TypeScript repository, exactly two public npm packages, `@echoregent/core` and `@echoregent/cli`. Positioning: “Open-source context middleware for LLM applications and coding agents, with policy controls and editable, source-cited memory.”

Core owns deterministic classification, a non-weakenable medical/legal/crisis protection floor, conservative compression, and explicit project/session memory. CLI imports core for the local HTTP API, provider proxy, and stdio MCP. Neither package loads proprietary weights, downloads models, sends telemetry, or automatically stores prompts. LLM requests go to the user's configured provider.

Implementation choices: Node 22.12+, ESM with compiled JavaScript and declarations; preserve the existing deterministic classifier by extracting it into core and reusing it from development code. Default compression collapses consecutive repeated log lines only in the newest plain-text tool result; earlier items, current user input, structured blocks, tools, cache controls and request metadata remain unchanged. This deliberately prioritizes protocol and cache-prefix integrity over aggressive savings. Exceptions forward the original request bytes. No response cache.

Memory defaults off. Explicit ephemeral or file mode requires project/session scope; file mode requires a directory and TTL. Store facts with source citations, support replacement/deletion/purge, deny protected content and protected sessions, and never search other scopes. Bound scopes in MCP to the server's configured project/session. Do not import old unscoped wiki files automatically.

`echoregent wrap codex` starts an ephemeral loopback proxy, configures a custom Responses provider with command-line overrides, forwards API-key authentication, verifies local routing before launch and reports actual routed requests after exit. No durable Codex edits are necessary, so undo is shutdown. Reject overrides that bypass routing. `doctor` checks health and optionally exercises the upstream Responses route. `mcp` uses the same engine. Models are intentionally unavailable in this release; document separate licensing and future explicit onboarding rather than ship an unverified downloader.

Advertise Codex only after running its actual executable against a controlled SSE Responses server including a tool call/result round trip. Tests cover structured content, ordering, authentication, incremental streaming, error passthrough, cache prefixes, scope isolation, retention, and packed installation without a checkout. Reproducible evidence must distinguish fixtures from provider-billed task measurements. Preserve existing uncommitted research/development work in place; do not commit it, publish to npm, or change repository visibility.
